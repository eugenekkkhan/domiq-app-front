# Domiq — Mini App

Мини-приложение для мессенджеров (Telegram Mini App + MAX): контент-хаб с новостями, статьями и видео, плюс встроенная админ-панель для управления контентом.

## Возможности

- Лента новостей и статей с просмотром отдельных материалов
- Раздел видео со встроенным плеером
- Админ-панель: создание и редактирование статей, новостей и видео (Markdown-редактор)
- Поддержка двух платформ: Telegram Mini App и MAX mini app (роутинг по basename)
- Тема интерфейса подстраивается под тему мессенджера

## Стек

React, TypeScript, Vite, MUI, React Router, @telegram-apps/sdk, Markdown-редактор (@uiw/react-md-editor)

## Запуск

```bash
npm install
npm run dev
```
